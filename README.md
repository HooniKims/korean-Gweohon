# 괴혼 국어 — 9품사 학습 게임

공을 굴려 **같은 품사끼리 모으는** 국어 학습 게임입니다.
[괴혼(Katamari Damacy)](https://namu.wiki/w/괴혼%20시리즈)처럼 굴릴수록 공이 커집니다.

중학생 대상이고, 태블릿·폰 터치와 PC를 모두 지원합니다.

---

## 어떤 게임인가

바닥에 단어가 붙은 사물들이 흩어져 있습니다. 공을 굴려 사물에 닿으면 공에 붙습니다.

- **맞는 품사**를 붙이면 → 점수를 얻고 공이 커집니다
- **틀린 품사**를 붙이면 → 「부착밀」이 되어 공이 무거워지고 느려집니다
- **공보다 큰 사물**은 붙지 않고 튕깁니다 → 더 키워서 와야 합니다

공이 커질수록 더 큰 사물을 먹을 수 있습니다. 이 「성장」이 게임의 핵심입니다.

첫 스테이지는 **명사**입니다. 120초 안에 명사 15개를 모으면 통과합니다.

### 9품사

명사 · 대명사 · 수사 · 동사 · 형용사 · 관형사 · 부사 · 조사 · 감탄사

품사마다 색이 다릅니다.

---

## 실행하기

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 **http://localhost:3100** 을 엽니다.

계측값을 보려면 `?debug=1`을 붙입니다 (fps, 공 지름, 좌표 등).

### 그 밖의 명령

```bash
npm test            # 테스트 213개
npx tsc --noEmit    # 타입 검사
npm run build       # 빌드
```

## 폴더 구조

```
src/
  game/     게임 규칙 — 순수 TypeScript. three도 React도 안 씁니다.
            성장 공식, 배치, 부착 판정, 점수, 굴림 물리 계산
  three/    3D 화면 — 공, 캐릭터, 사물, 카메라, 무대
  ui/       HUD, 결과 화면, 시점 위젯
  input/    키보드 · 터치 · 마우스
  store/    zustand 스토어

public/
  models/   3D 모델 (Tripo 제작 + Kenney CC0)
  data/     words.json — 품사별 단어 사전
  fonts/    Paperlogy

docs/superpowers/
  specs/    설계 문서
  plans/    구현 계획
  qa/       플레이테스트 기록
```

**`src/game/`은 순수 TypeScript입니다.** three나 React를 import하지 않습니다.
덕분에 게임 규칙 전체를 Vitest로 빠르게 검증할 수 있습니다. 이 경계를 지켜 주세요.

## 3D 에셋

- **캐릭터 · 사물 · 배경** — [Tripo](https://www.tripo3d.ai/)로 만든 것
- **나무 · 바위 · 풀 · 꽃 등 장식** — [Kenney](https://kenney.nl/) CC0
  (라이선스: [assets/kenney/CREDITS.md](assets/kenney/CREDITS.md))

Tripo 원본 GLB는 약 430MB라 git에 넣지 않았습니다.
압축본(전체 17.4MB)만 `public/models/`에 들어 있고, 이것만으로 게임이 돌아갑니다.

압축은 `gltf-transform`으로 합니다(단순화 → WebP 텍스처 → Draco):

```bash
npm run assets:optimize
```
