# Tripo 생성 프롬프트 시트 — 55개

설계 문서: `docs/superpowers/specs/2026-08-01-korean-pos-katamari-design.md`

## 작업 규칙

1. 아래 프롬프트를 그대로 Tripo에 붙여 넣는다 (수정 불필요)
2. 생성된 GLB를 다운로드해 `assets/tripo/raw/<파일명>.glb` 로 저장
3. `assets/tripo/manifest.json` 에 프롬프트·생성일 기록
4. 나중에 `gltf-transform` 으로 압축해 `public/models/` 로 보낸다
